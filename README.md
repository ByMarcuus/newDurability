# Introduction
This repository presents the implementation of the "New Durability" mod for both "Fallout: New Vegas" and "Fallout 3".
Because each game has its own plugins and technical requirements, each implementation looks different.

# What does this mod do?
It overhauls durability using coherent, RPG-inspired formulas.
Weapons degrade with each shot fired, and armor degrades with each hit received. Furthermore, low skill can accelerate the process.
Weapon durability scales with Skill Points, while armor durability scales with SPECIAL stats.
